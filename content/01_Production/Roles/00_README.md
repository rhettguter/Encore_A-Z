# Production Roles — README

*Role definitions for everyone involved in a production. Organized by team.*

## What lives here

Five subfolders: **Creative Team/** (Director, Choreographer, Music Sup, plus **Associates/** apprentice roles), **Design Team/** (Set, Costume, Light, Sound, Prop designers + coordinators), **Production Team/** (Production Manager, Stage Manager, Producer, Technical Director, etc.), **Crew, Carps and Board Operators/** (hands-on crew).

## What doesn't live here

How-to-do-the-work knowledge lives in `../Guides/`. The Encore-specific directing philosophy lives in `../Guides/Director's Guide.md` (complementary to `Creative Team/Director.md`).
