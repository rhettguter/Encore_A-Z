# Show Bible

## Introduction

The show Bible is the definitive reference document for your production—containing all essential information needed to mount and run the show successfully. For Encore productions, which serve both artistic and educational purposes, a well-organized show Bible is particularly important as it models professional documentation for young artists.

"The show Bible is your insurance policy, roadmap, and the memory of your production all in one."

The show Bible serves as:

- A central reference source for all production details
- The tool for maintaining production consistency
- A problem-solving resource during tech and performances
- A bridge connecting all departments
- An archival record after the production closes

## Core Components

### 1. Production Information

- Title page (show name, dates, venue)
- Creative and production team list
- Cast list with roles
- Mission statement or artistic vision

### 2. Contact Information

- Team member contacts (phone and email)
- Cast member contacts (including parents/guardians)
- Theater staff contacts
- Emergency contacts

### 3. Schedules

- Rehearsal calendar
- Technical rehearsal schedule
- Performance schedule
- Special events

### 4. The Annotated Script

**This is the heart of your show Bible:**

- Use a clean script with ample margins for notes
- Number all pages
- Include clear blocking notations
- Mark all entrances and exits
- Note set changes and furniture movements
- Mark prop handoffs
- Label all technical cues

**Develop a consistent notation system:**

- Create clear symbols for different movements
- Use color-coding effectively
- Include a key explaining your notation system

See [[Encore Script Notation]] for Encore's standard.

### 5. Cue Sheets

Create separate sheets for each department:

- **Lighting Cues:** Numbers, descriptions, timing
- **Sound Cues:** Numbers, descriptions, sources
- **Scene Shifts:** Personnel assignments, movement details
- **Special Effects:** Timing, execution notes

### 6. Tracking Documents

- **Character Tracking:** Which characters appear in each scene
- **Prop Tracking:** Who uses what, when, and where
- **Costume Tracking:** Full costume plots, quick changes
- **Set Tracking:** Scene-by-scene configurations

### 7. Ground Plans

- Basic set configurations
- Furniture placements
- Wing space organization
- Prop table layouts

### 8. Emergency Information

- Theater emergency procedures
- First aid locations
- Emergency contacts
- Safety notes for potentially hazardous elements

## Organization Tips

### Physical Organization

- Use a sturdy 3-ring binder (2–3 inches)
- Include tabbed dividers for major sections
- Protect frequently used pages with sheet protectors
- Use color-coding and sticky tabs for quick reference

### Digital Components

- Keep digital backups of all documents
- Store in the production Google Drive
- Use consistent file naming
- Maintain version control

**Important:** Organize your Bible with the most frequently needed information most accessible. Consider what someone else would need if they had to step in for you.

## Building Process

The show Bible develops throughout the production process:

### Pre-Production

- Create the basic structure
- Gather preliminary information
- Set up tracking templates

### Rehearsals

- Add blocking as it develops
- Update tracking documents
- Note special requirements

### Pre-Tech

- Finalize all cue sheets
- Complete all tracking documents
- Ensure all technical information is included

### Tech/Performances

- Add technical adjustments
- Document solutions to issues
- Note any authorized changes

## Using Your Show Bible

### During Technical Rehearsals

- Use for calling all technical cues
- Reference for resolving questions
- Document changes and adjustments

### During Performances

- Position for optimal viewing while calling
- Mark called cues consistently
- Have emergency information easily accessible
- Update as needed with any changes

### After Closing

- Clean up temporary notes
- Document any permanent changes made
- Follow Encore's archiving procedures
- Create a production summary

A well-maintained show Bible not only supports the current production but serves as a valuable resource for future Encore productions. It reflects your organizational skills and commitment to the production's success while providing young artists with a model of professional theatrical practice.
