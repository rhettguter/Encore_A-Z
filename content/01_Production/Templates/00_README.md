# Production Templates — README

*Reusable forms and templates used during production. Copy a template and customize for each show.*

## What lives here

Audition Form, Daily Call Report Template, Show Launch Template, Show Start Protocol, Creative Team Proposal Template, Template Youth Agreement, etc. Plus one subfolder: **Facilities Use Templates/**.

## What doesn't live here

Contract templates from Drive were intentionally not migrated (kept in Drive in .docx for signing). Foundational docs like Mission/Vision/Values or Ten Commandments should arguably move to `00_Processes/` — currently here for historical reasons.
